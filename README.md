# PrettySnowing

A minecraft fabric mod that reworks the visual snow behavior in a fully client-side vanilla way.
This is my first attempt at making a minecraft mod due to frustration of not being able to find the mod/a collection of mods that would fix the vanilla snow behavior. In my opinion, this means doing the following in cold places:
- Render snow under trees and all blocks that aren't completely solid
- Change the textures of all foliage/flowers to be colder/frosted
- Add a base layer of snow to the top of all blocks

Cold places being anywhere where the temperature is lower than 0.15.

Currently, I'm just testing out the scope of doing this alongside looking at other fabric mods which implement parts of what I want to do. Its possible I give up due to complexity, though if I do get somewhere I'll leave it here and someone can PR the finishing touches.

These are the fabric mods that did most of the heavily lifting for me to latch on:

https://github.com/ToBinio/better-snow-coverage

https://github.com/IMB11-Mods/SnowUnderTrees

https://github.com/IlyRac/TrueSnow

The starting point of this mod was Better Snow Coverage 0.4.2+mc26.2 due to its MIT license and nice config.

I did not take any source code from the other two mods, merely studied how they worked and applied it myself.

I would also like to state none of the code for this mod is or will be generated by an LLM, though I will be using it to ask questions and help debug.

Below are all the dependencies. I don't really know the lower limit of these values per-se, but the stated ones are what I use in development and testing. The list may update over time, say for the minecraft and java versions, as I don't think I'll be upgrading/downgrading this mod between versions; you can always do that yourself with a PR.

# Necessary dependencies

Minecraft >= 26.3

Java >= 25

Fabric Loader >= 0.20.1

Fabric API >= 0.165.0+26.3

Sodium >= 0.9.3-beta.1+mc26.3

YACL >= 3.9.7+26.3-fabric

# Not necessary, but desirable dependencies

Mod Menu >= 21.0.0

Iris >= 1.11.7+26.3-fabric

# Building from source

Install Java JDK >= 25 (Project uses Adoptium Eclipse Temurin OpenJDK 25.0.5_8) and make sure its added to PATH

Unzip the downloaded project files

Run "./gradlew build" on linux or "./gradlew.bat build" on windows

Personally, I develop on VSCode with the Extension Pack for Java, so use that if you don't know where to start

If you want to help develop the mod, send a PR with your commits. Otherwise make your own fork, just don't use the same name.

What the project uses, does not need to be installed manually:

Gradle >= 9.8.2
Fabric Loom >= 1.19.3
